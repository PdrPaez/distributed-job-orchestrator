# Contributing

## Workflow

- `main` is the stable branch.
- `dev` is the integration branch.
- Work is organized by `DJO-XXX` cards.
- Branches use `<kind>/DJO-XXX-short-description`.
- Commits use `[AREA][DJO-XXX] concise English description`.

Validate relevant backend and frontend checks before integrating work into `dev`.
